# ecospeak
EcoSpeak es una app en Python que enseña vocabulario sobre el cambio climático en inglés evalutando la pronunciación en tiempo real.  🎮 Instrucciones Ejecuta main.py e instala requirements.txt.  Elige dificultad (1, 2 o 3).  Lee la palabra ambiental en español.  Oprime ENTER y pronuncia su traducción en inglés al micrófono.
